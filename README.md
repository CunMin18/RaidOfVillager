# 中文简介  
## **村民拾八模组整合（视频第1-3期）**  

### - 注意：由于视频需要，未考虑可玩性，所以该模组存在BUG多/玩法不完善等问题，且模组本身未来不一定会继续更新，仅供玩家体验。  
### - 目前模组只支持Java Fabric 1.20.4版本。  

    
包含内容:  

1.村民攻击/感染僵尸   
- 村民识别到附近有僵尸或者袭击者，村民会切换到木剑攻击目标，如果僵尸被村民击杀，僵尸会被转化为村民。 

2.僵尸无法在白天自燃  

3.铁傀儡加强，并且会使用泥土搭高  
- 如果铁傀儡攻击目标为玩家。
- 它会根据玩家所带装备进行评分，然后根据评分决定是否触发保护机制。

保护机制:强制对目标进行搭高，将其送上天。

4.村民袭击:任何玩家所在的区域如果存在前哨站，且前哨站范围内有铁傀儡，则会触发村民袭击。
- 村民袭击会在范围内持续生成村民卫道士和铁傀儡。
- 村民袭击可以叠加。
- 新生物：卫道士村民，目前仅能自然生成或者通过指令 /**summon raid_of_villager:vindicator_villager** 生成

5.绿宝石工具/盔甲  
- 合成方式和其他材料相同。 


      
# English 
## **Integration of CunMin18's mod (video phase 1-3)**

### - Note: Due to the need of video, the playability is not considered, so there are many bugs/imperfect gameplay in this module, and the module itself may not be updated in the future, which is only for players to experience.
### - The current module only supports Java Fabric version 1.20.4.


Contains content:

1.Villagers attack/infect zombies
- When the villagers recognize that there are zombies or attackers nearby, they will switch to wood blade to attack the target. If the zombies are killed by the villagers, they will be transformed into villagers.

2.Zombies can't spontaneously ignite during the day.

3.Iron golems are strengthened, and they can use soil to build high.
- If the iron golem attacks the player.  
- It will score according to the equipment the player carries, and then decide whether to trigger the protection mechanism according to the score.  
- Protection mechanism: force the target to be set high and send it to the sky.  

4.Villager Attack: If there is an outpost in any player's area and there is an iron golem within the outpost, it will trigger a villager attack.
- Villagers' attacks will continue to generate villagers' guardians and iron puppets within the scope.
- Villager attacks can be superimposed.
- New creature : Vindicator villager. It can only be spawned natually or be spawned by command /**summon raid_of_villager:vindicator_villager** .

5.Emerald tools/armor
- The synthesis method is the same as other materials.
